# Digital Plus — Borlèt Admin Demo

Prototype frontend inspiré de l'organisation visible dans la capture fournie.

## Inclus
- Dashboard
- Vandè
- Tiraj
- Lo ki soti / limites
- Rapò
- Statistik
- Fich
- Branch
- Machines / Terminaux
- Paramèt
- Navigation responsive

## Important
Sa a se yon prototype frontend ak done demo. Li pa konekte ak yon database, li pa gen login production, ni li pa trete lajan reyèl oswa pari reyèl.

## Etap production
1. Backend API + PostgreSQL/MySQL
2. Auth + rôles admin/super-admin/vandè
3. Enskripsyon ak authentication pou machines
4. Audit logs + backups
5. Real-time status
6. Reports/export
7. Security hardening
8. Legal/compliance review pou nenpòt operasyon jwèt reyèl.
